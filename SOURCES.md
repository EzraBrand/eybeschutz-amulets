# Sources

Status: **have** = file in `sources/`; **missing** = link known, not downloaded.
Page counts are PDF pages. "OCR" = quality of the existing text layer.

**Caveat:** for the Emden books, the date given is the first printing (from the
he.wikipedia list). Only the *Luḥot Edut* editions and *Sefat Emet* were checked
against the scans. A HebrewBooks scan can be a later reprint, so check each title
page before you cite a page.
